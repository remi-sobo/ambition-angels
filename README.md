# Ambition Angels website

The public site at ambitionangels.org: the pages, the teen games, the career library and a small website admin. BloomOS lives in its own repo and is not part of this one. See `CLAUDE.md` for how the code is laid out and `specs/bloomos-repo-split.md` for where the line between the two sits.

```bash
npm ci
npm run dev   # http://localhost:3000
npm test
```
