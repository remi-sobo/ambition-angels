# Ambition Angels

Ambition Angels helps young people explore careers through introships,
trusted-adult conversations, teen games, and program pathways.

This repo contains the public site, teen experiences, donation flows, meeting
scheduler, and internal admin surfaces.

## Running locally

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run build
npm run lint
npm test
```

## Project rules

The current project guidance lives in `PROJECT.md`. The public-site build
record lives in `specs/site-redesign-v2.md`.

Before changing the public site, read both files. Keep copy specific, use
real stats from `lib/stats.ts`, and do not add placeholder testimonials,
invented partner names, generic SaaS sections, or unused visual effects.
